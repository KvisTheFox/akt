# Бенчмарки

Сравнение akt с C, C++, Rust и Zig на одинаковых алгоритмах.

```bash
powershell -ExecutionPolicy Bypass -File benchmarks/run.ps1
```

Скрипт компилирует каждый тест (`-O3 -march=native` для C/C++,
`--release` для akt, `-O` для Rust, `-O ReleaseFast` для Zig),
запускает 3 раза и пишет лучшее время в [`RESULTS.md`](RESULTS.md).

## Тесты (`benchmarks/suite`)

| тест | что меряет |
|---|---|
| `fib` | рекурсия, вызовы функций (`fib(32)`) |
| `loop` | целочисленный цикл, 100 млн итераций |
| `sieve` | решето Эратосфена до 5 млн, память + ветвления |
| `matmul` | умножение матриц 256×256, f64 |
| `hash` | FNV-1a по 16 МБ, побайтовая работа с памятью |

Каждый тест печатает результат; скрипт сверяет, что все языки дают
одинаковый ответ.

Старые одиночные бенчмарки (`benchmarks/fib.akt` и т.п.) оставлены для
истории.
