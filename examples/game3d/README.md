# akt 3d — мини-игра на akt

Простая 3D-игра: соберите кубы за 60 секунд.

- `WASD` — движение
- мышь — обзор
- `R` — начать заново
- `Esc` — выход

Счёт и таймер — в заголовке окна.

## Как работает

- язык: akt (`.akt` → C11 → exe);
- окно и ввод: GLFW 3.4;
- графика: OpenGL 1.1 (fixed-function);
- C-заголовки подключаются напрямую через `cinclude`, объявления
  разбираются компилятором автоматически;
- библиотеки (`glfw3`, `opengl32`) подключены через `katek.toml`;
- сгенерированный C и кэш заголовков лежат в `.kache/`, исходники
  остаются чистыми.

## Сборка и запуск

```bash
katek build
target/app.exe
```

или:

```bash
katek run
```

GLFW 3.4 (Win64) нужно положить в `vendor/glfw-3.4.bin.WIN64`
(официальный `glfw-3.4.bin.WIN64.zip` с GitHub).

## Исходники

- `src/main.akt` — вся игра (около 250 строк);
- `katek.toml` — include/lib/link для GLFW и OpenGL.
